# State Branch and Minor Party Membership close on supersession by the next distinct affiliation

**Status:** Accepted

ADR-0002 leaves State Branch and Minor Party Membership permanently open-ended because OpenAustralia gives no signal for when someone actually joined or left a party branch — that remains true for the *start* of a membership. This ADR adds an exception on the *end* side: whenever a person's next distinct party affiliation is observed, whatever came before it is closed, dated to when that next affiliation begins. Concretely, all of the following close a State Branch or Minor Party Membership:

- **A different state within the same major party family** — e.g. Barnaby Joyce: Nationals Senator for Queensland, then — after a gap — Nationals MP for New England, NSW. The Queensland State Branch Membership closes the day the NSW one begins.
- **A switch to a different party altogether** — major or minor. You cannot hold active state/minor-party membership in two different parties at once, so observing the switch is positive evidence the earlier one ended.
- **A switch to Independent.** Independent is not itself a party — it produces no Group and no Membership of its own — but the transition into it is still real evidence a prior State Branch or Minor Party Membership ended, so it closes whatever came immediately before it. Barnaby Joyce's NSW Nationals State Branch Membership closes when he goes Independent in November 2025, not when he later joins Pauline Hanson's One Nation in December.
- **A switch from one Minor Party to another Minor Party** — same reasoning as the state case, just without a state dimension: Minor Party has no Federal/State split (CONTEXT.md), so there's only one Membership to close and one to open.

In every case, the closing date is the *start date of the next affiliation* — not the closed period's own natural end date. We don't know when the old membership really ended, only that it must have ended by the time we have positive evidence of the new one starting. This differs from Federal Branch, which is unaffected by this ADR and keeps closing on its *own* natural end (ADR-0002) — that's tied specifically to parliamentary tenure, a separate and already-correct signal.

Only the person's *final* observed affiliation for a given family/minor-party lineage stays open — there being nothing later to supersede it is the only thing that keeps ADR-0002's original "we don't know when it ends" position in force. A state or party that simply *resumes* after a gap (e.g. Barnaby's two separate Nationals (NSW) stints either side of his 2017 disqualification) is treated as the same, uninterrupted affiliation — it isn't superseded by itself.

Implemented in `OpenAustralia::Interpretation::ResolvePartyAffiliations` (`superseded_on` on `PartyAffiliationPeriod`, computed by walking the full chronological chunk timeline — including Independent stretches, which carry an identity for this purpose despite producing no period — and chaining each distinct affiliation identity to the start date of the next one) and applied in `OpenAustralia::Interpretation::RecordMembershipsAndPositions#record_state_branch` / `#record_minor_party`.

**Known limitation, accepted:** if a person returns to an *already-superseded* identity after an intervening, different one (e.g. hypothetically: NSW → Independent → NSW again), the earlier NSW stint is treated as superseded by the Independent stretch and not reopened by the later return — the chain only walks forward through *distinct* identities in order of first occurrence. This isn't a realistic shape for federal politicians in practice (state branches don't get re-joined after being formally superseded in the ordinary course of a career), so it's accepted rather than solved.
